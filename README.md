# 📖 Descripción General

Este repositorio corresponde al desarrollo de la **Práctica 1: Proceso ETL**, realizada como parte de la asignatura de Analítica de Datos.

Debido a que cada integrante desarrolló una implementación distinta del proyecto, el repositorio fue organizado mediante ramas independientes para preservar cada propuesta de trabajo y facilitar su evaluación.

La rama **main** funciona únicamente como punto de entrada y documentación general del proyecto. El desarrollo completo de cada propuesta se encuentra en las ramas específicas de cada integrante.

# 🎯 Objetivo de la Práctica

Implementar un proceso de preparación de datos utilizando PostgreSQL sobre el dataset **Global Superstore Sales**, aplicando las etapas de extracción, transformación y validación de información.

El objetivo final consiste en obtener una estructura de datos limpia y consistente que pueda ser utilizada para análisis posteriores.

---

# 📊 Dataset Utilizado

**Nombre:** Global Superstore Sales

**Origen:** Kaggle / Tableau

Características generales:

* Más de 51,000 registros.
* Información de órdenes comerciales.
* Clientes.
* Productos.
* Categorías.
* Mercados y regiones.
* Ventas.
* Descuentos.
* Costos de envío.
* Ganancias.
